# Metadata workspace

Mode: Operate. Target: src/App.tsx.

## Direction contract

THESIS: Make the hidden contents of an image legible, then let the user remove them confidently. The working file and its metadata lead; no promotional hero or dashboard cards.

OWN-WORLD: Warm neutral surfaces, a quiet forest-green action, system sans typography, hairline separators and compact native controls. Amber marks exposure requiring attention, not alarm. Dark mode remains equally legible.

STORY: Select images, scan the privacy summary, inspect grouped or raw values, choose metadata families, clean, compare and download a verified copy. The original stays available.

FIRST VIEWPORT: A compact header and plain task heading precede the file drop area. Once loaded, a file rail sits beside the inspection area; removal rules and before/after status sit below the details. The primary action is adjacent to its rules, not in a marketing section. Mobile stacks the same flow without hidden controls.

FORM: Direct code implementation under the user's settled Emil Kowalski + Impeccable series direction. Concept seed key3690ce01 ran degraded after a network-enabled retry: no challengers or quality-bar boards were available. The user-pinned direction takes precedence over its assignment. Signature interaction: the original/cleaned switch changes inspection of the same file while the verified output action remains explicit. No entrance animation; subtle pointer press feedback only, with reduced motion support.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
