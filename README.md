# EMeta

**Privacy-first metadata viewer and cleaner.**

Drop a file, inspect the metadata it contains, and remove metadata before sharing it.

> Free. Open source. Your files stay on your device.

## Planned features

- Image metadata inspection
- EXIF/IPTC/XMP display
- GPS/location detection
- Camera/device information
- Creation/modification timestamps
- Author/software metadata where available
- One-click metadata removal
- Batch cleaning
- Before/after comparison
- Local-first processing
- Light and dark themes
