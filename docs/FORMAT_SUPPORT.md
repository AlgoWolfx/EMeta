# Format support and verification

Selection removes whole metadata families, not individual semantic fields. EXIF includes GPS, dates, thumbnails and camera details together. This verifies selected supported metadata removal, not anonymity or redaction.

| Format       | Cleaning scope                                                                                         | Verification                                                                                                                                                        | Retained / refused                                                                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JPEG         | EXIF/XMP APP1, Photoshop/IPTC APP13, comments, selected other non-rendering records/trailers           | Reparse, scan bytes, required orientation and browser decode; downloaded RGBA compared in tests for all eight orientations                                          | ICC/JFIF/Adobe; MPF and ambiguous rotation inspection only                                                                                                              |
| PNG/APNG     | EXIF, plain/compressed text, XMP, tIME                                                                 | CRC/ranges, exact image/animation/color chunks, browser decode                                                                                                      | Unknown ancillary chunks retained; unknown critical chunks refused; text inflation capped at 1 MB                                                                       |
| WebP         | EXIF/XMP, repaired RIFF size and VP8X flags                                                            | Reparse, exact image/animation/color chunks, required orientation, browser decode                                                                                   | ICC/unknown chunks retained; conflicting orientation refused                                                                                                            |
| Classic TIFF | EXIF/GPS directories, IPTC/Photoshop/XMP, known descriptive text and dates                             | Bounded IFD rewrite, preserved offsets and image strips/tiles, reopened structure; independent Pillow pixel comparison in tests                                     | Orientation/color/rendering tags and unknown private tags retained; BigTIFF, cyclic/overlapping/unsupported directories refused                                         |
| HEIC/HEIF    | EXIF/XMP items, payload extents and references                                                         | Rebuilt item/location/reference tables without moving images; erased metadata bytes, identical retained extents; libheif decodes and compares every supported image | Color/container display properties retained; external offsets, protection, unsafe overlap, unsupported layouts and ambiguous EXIF rotation refused; AVIF is unsupported |
| PDF          | Info properties (author/title/dates/editor) and XMP                                                    | Reachable catalog copied into a fresh context, removal rechecked; every page rendered with PDF.js and compared at scale 1 before download                           | Content/forms/annotations/attachments retained; encrypted, signed, XFA and PDFs over 50 pages refused for cleaning; page render limited to 4 MP                         |
| MP4/MOV      | Supported container user tags, known XMP UUID, header creation/modification timestamps and track names | Fixed-size erased/free records, reopened boxes, identical mdat bytes; independent FFmpeg decoded frames/audio hashes in tests                                       | Timing, track geometry/rotation, samples/subtitles and unknown UUID/private boxes retained; encrypted/timed metadata tracks refused                                     |
| WebM/MKV     | Tags, title/track/editor names, DateUTC; affected CRC records                                          | Same-size Void records, required app elements retained empty, reopened EBML and identical Cluster data; independent FFmpeg decoded frames in tests                  | Tracks, timestamps, subtitles, attachments retained; encrypted/compressed tracks, timed metadata and unknown-length Clusters refused                                    |

HEIC, TIFF and video commonly remain the **same byte size**: metadata bytes are erased and references removed while retained content stays at its original offsets. PDF rewriting can increase or decrease size. File size alone does not prove removal.

Browser limits: 30 files, 50 MB/file, 200 MB/batch, 40 MP/image. HEIF decoding caps image count at 30. PDF verification caps pages at 50 and each rendered page at 4 MP. Bounded parsers reject unsupported structures instead of producing an unverified copy.

## Privacy limits

ICC/rendering headers, unknown chunks/tags, filenames, filesystem dates, visible text/watermarks, subtitles and information inside attachments can identify someone. EMeta does not search for steganography or promise forensic sanitization. Required rendering information can remain. No backend fallback or upload is used.

## Evidence limits

Fixtures are synthetic; tests cover supported representative layouts. HEIF comparisons use the bundled libheif decoder, PDF comparisons use PDF.js at verification resolution, TIFF uses independent Pillow, video uses independent FFmpeg. Preservation checks additionally compare compressed payload bytes. These checks do not establish all codecs, unusual camera containers, every PDF feature or physical-device compatibility. Firefox/Safari and real camera/document collections remain release checks.
