# v1 issue implementation map

The implementation follows the four AlgoWolfx/EMeta issues below. This map documents capabilities and evidence; it does not close issues or declare a deployed release.

| Issue                                                                 | Implementation                                                                                                                                           | Evidence                                                                                                              |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [#1 Foundation/pipeline](https://github.com/AlgoWolfx/EMeta/issues/1) | React/TS architecture, design context/tokens, picker/drop, local worker queue, signature adapters, isolated errors, themes, synthetic fixtures           | Structural-refusal unit tests; drag/drop, cancel, limits and theme/a11y browser tests                                 |
| [#2 Inspection](https://github.com/AlgoWolfx/EMeta/issues/2)          | JPEG/PNG/WebP EXIF/IPTC/XMP, semantic groups, sensitive highlighting, search/raw fields; TIFF inspection                                                 | Known GPS/camera/creator/software and real IPTC/XMP/compressed PNG text fixtures                                      |
| [#3 Safe removal](https://github.com/AlgoWolfx/EMeta/issues/3)        | Selected families/all-safe default; lossless rewrite; rotation retained; output reparse/verification/browser reopen; before/after and verified downloads | Eight orientations, exact downloaded pixels, selection, idempotence, progressive markers and ambiguity/refusal checks |
| [#4 Batch/expansion](https://github.com/AlgoWolfx/EMeta/issues/4)     | Bounded sequential batches, ZIP/individual downloads, duplicate names/errors; verified HEIC/HEIF, classic TIFF, PDF and video adapters                   | ZIP/collision/error browser tests; FORMAT_SUPPORT.md                                                                  |

The user subsequently authorized full format expansion, SEO and EQR's seven-language support. Supported classic TIFF, HEIC/HEIF, PDF and MP4/MOV/WebM/MKV cleaning is now implemented with documented refusal modes and preservation checks. Four static format guides in seven languages and configurable canonical/hreflang/sitemap/schema metadata are also included. The interface preserves files and verified results while switching languages; Arabic uses RTL. This does not close GitHub issues or publish a release.
